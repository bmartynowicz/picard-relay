## Recommended next enrollment

Brian selected the existing Oracle host plus **GitHub public-project CI**. Use GitHub standard public runners only for this repository's CI; general data processing still needs an eligible VM/backend. Provider selection does not verify Oracle's account entitlement or enable broker dispatch.

For each account, record privately: resource identity/region/architecture, workload restrictions, actual remaining allocation and reset time, quota evidence timestamp/expiry, preventive billing settings, network/storage charges, least-privilege access and pinned transport identity. No credentials belong in the public repository. Unknown entitlement or cost must leave the resource disabled.

Prove two-provider operation with separate fixed jobs, authenticated dispatch, measured resource use, durable invocation IDs, bounded logs/results and retrievable artifacts. Exercise unavailable capacity, exhausted quota and uncertain remote outcomes without automatic retry. Until those checks pass, the full board task's definition of done remains open.

## Authenticated Oracle assessment

On November 4, Brian signed in to the existing Oracle Console. Read-only checks distinguished permanent resource eligibility from promotional credits; the VM has an explicit Always Free label. The AMD micro quota applies to the VM's own domain; an initial different-domain query showed zero and was not used as its entitlement. Host metadata and the Console agree on the selected domain. The inspected root-compartment inventory contained one VM; this is not an assertion of zero resources in every compartment/region.

The VM's listed 1 OCPU/two logical CPU threads must not be interpreted as a full sustained free core: Oracle documents the micro shape as burstable. The boot disk is 50 GB; Linux's smaller root filesystem is a separate measurement. No ARM/GPU machine or extra instance was provisioned. Account-wide egress/storage totals, actual charges, remaining trial credits/expiry and preventive billing settings remain unverified because the cost and subscription views rendered blank. Public [Free Tier documentation](https://docs.oracle.com/en-us/iaas/Content/FreeTier/freetier.htm) distinguishes expiring trial credits from Always Free resources, but does not replace this account's missing billing readback.

Private screenshots/snapshots and SSH profile paths stay outside the repository. The public source records only the bounded findings above. The Oracle MCP observer cannot turn a machine metric or dated manual Console finding into live billing approval; cloud dispatch stays disabled.
